# 1.0.0 — 默认最新版发布

日期：2026-11-09。

按用户要求，将当前最新版统一命名为 **1.0.0**，并在 GitHub Releases 中设为 **Latest**。README 的主入口改为“获取最新版”，旧版本保留。

功能与 0.14.29 一致：数字输入阅读页数（默认 20，0 为全部）、可选跨设备任务标记、409 兼容判断、精读与核验、保存和归档均保持。插件 ID 不变，可以在原安装上升级；仍为手动安装 XPI，不会自动替用户重启 Zotero。

本次只有 manifest、设置页版本标识及 CLI 客户端版本标识三个生产文件变化；逐文件比对确认差异仅为版本字符串。348 项自动检查、语法/XML 与源码打包一致性检查通过。没有重复运行原生测试；0.14.29 的 20 项定向隔离检查作为既有证据保留，不声称本次重测。可选协作的真实服务兼容性等限制也保持原说明。
