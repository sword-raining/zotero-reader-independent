# 0.14.8 — 设置对齐、合并归档与简短连接测试

日期：2026-11-08；本地构建，未代为安装或推送远端。

- 自动修订开关独立成行，同时处理篇数和最多修订次数对齐；模型卡片内的连接状态及按钮保持对齐。
- 模型页仅保留精读、后台检查。检查请求附带可选分类，返回核验结果时一并给出归档建议，不再为正常自动归档单独调用模型。保留完整核验、修订后复查，仅采用最后通过的一轮建议。
- 笔记成功保存后才准备归档弹窗，未经确认不改变分类。建议与保存内容、来源分类和建议范围绑定；人工修改稿、旧稿缺少建议或依据变化时可以手动选择，不自动追加模型调用。明确点击“让检查模型建议”时才使用检查模型另发一次请求。旧独立归档模型偏好保留但不再使用。
- 普通连接测试只发送一句问候，收到非空最终回复即可确认连通，回复显示在相应卡片里；切换配置后清除旧回复。显示当前阶段和耗时，等待模型目录时也能停止。结构化输出验证仍可主动勾选，模型自述名称不作为真实型号的证据。

验证：169 项自动检查通过，25 项隔离原生检查通过（工作流 8、归档 11、设置 6）。合成端到端验证正常文献为精读＋核验两次调用；两篇含一轮修订总计 6 次调用，独立自动归档调用为 0。原生设置窗口实际检查宽度为 1200、920、800 像素（宿主最小宽度为 800，未声称验证更窄的窗口）。

另在全新隔离 profile 使用本机已登录的 CLI，各发送一次不含论文的问候：Codex 默认配置 7.145 秒、Antigravity 默认配置 22.185 秒，均收到回复；这不代表所有型号和强度已验证，也不证明等待时间来自哪一阶段。未修改真实文库、全局配置或复制凭据；未重跑真实论文。归档合并后的真实论文质量和真实双机同步仍待验证。
