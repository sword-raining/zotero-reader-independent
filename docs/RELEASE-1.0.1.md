# 1.0.1 — 一键开始恢复未完成任务

日期：2026-11-10。

修复“检查未完成”“草稿待复核”只有查看结果、一键开始漏掉这些任务的问题：队列旧记录可能仍标为没有草稿，即使草稿文件已经生成。现在开始前读取实际草稿，启动和任务结束后也会刷新恢复状态。

同一个“开始”按钮同时处理：

- 有完整草稿：继续检查；待复核稿按现有流程修订并复查。
- Zotero 关闭、暂停或失败时尚未生成初稿：在状态允许时重新排队，保留旧记录和文件。
- 人工编辑、已保存或缺少必要材料：保留并提示，不静默覆盖。

队列运行时该按钮仍为“全部暂停”。新版本不会自动重跑这些已停止或检查未完成的任务；升级并重新打开 Zotero 后，点击“开始”即可。已有结果和个人分类不改动。如果服务仍返回额度或频率限制，需恢复可用额度后再继续，本次修改不绕过服务限制。

验证：352 项自动检查通过；9 项 Zotero 10.0.8 隔离文库检查通过，包括实际点击开始/暂停、并发上限、草稿续检、关闭中断恢复和人工修改保护。全部合成数据，真实模型请求 0，未操作个人文库。
