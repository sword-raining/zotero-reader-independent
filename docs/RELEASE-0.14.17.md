# 0.14.17 — 自动归档与旧稿清理兼容

日期：2026-11-08；本地构建，未自动安装或推送。

- 用户最新决定替代此前逐篇确认要求：归档方式改为自动归档、逐篇确认、不自动归档三种，新版默认自动。旧 classification.enabled 布尔开关保留但不再解释为新模式；明确选择的 classification.mode 优先，异常显式值按关闭处理。
- 自动模式仅在本轮精读完成、笔记保存、具有本轮核验生成的有效推荐后执行：添加推荐分类，存在原待处理归属时移出该归属，其他已有分类全部保留。模型的其他移出建议不自动执行。无可靠建议、来源变化、取消或写入失败时保留笔记与原分类，显示原因，不强行归档。
- 自动操作绑定当前 worker、当前任务和已保存笔记，并复用同一原生分类事务及回滚。记录 approvalMode 区分自动/手动授权。没有额外分类模型请求；旧待确认建议不会因安装、渲染设置或更换模式而自动补执行。主动手动归档仍可用。
- 清理问题原因是旧版只记录最新 reading.md 的指纹，旧 review-needed.md 没有校验记录，导致整项保留。新版记录各次生成 Markdown 的指纹；对于无指纹、非当前结果的历史文件，仅在可用已保存草稿/核验记录逐字重现并比对 SHA256 时兼容清理。当前稿件的指纹不符、额外文件或无法重现的旧稿继续保留。
- 清理反馈移至按钮下方并滚动到可见位置，明确显示阻塞文件名和原因，不再把“无法证明旧稿未变”笼统说成人工修改。

验证：216 项自动检查通过；8 项隔离自动归档检查及 12 项隔离清理/队列回归通过。合成模型与文库验证自动完成、无弹窗、保留既有分类、仅用最后通过的核验建议、无建议保留、事务失败回滚、手动与关闭模式，以及旧中间稿清理和修改稿保护。真实模型请求为 0。

对截图那条旧任务还做了只读兼容核对：最终稿与当前草稿指纹均一致；旧待复核稿可由历史记录逐字重现，修复后的完整检查接受该目录。真实缓存与文库均未清理或改动。本轮没有验证真实论文自动分类的推荐质量。

建议等待当前运行任务结束后安装并重启。之后的新完成任务默认自动归档；原来保留的旧完成记录可再点一次“清理已完成任务”。
