# 0.14.6 — 建议归模型，归档选择归用户

日期：2026-11-07。仅本地构建，未安装个人 Zotero 或推送远端。

1. 笔记保存后，显示模型推荐分类及理由；推荐项默认不勾选。
2. 用户决定是否采用，并可搜索、多选其他现有分类。
3. 确认前列出新增分类；默认保留待处理分类，单独勾选“同时移出”才移出。
4. 已有分类不因未勾选而删除；PDF、笔记和人工标签保持原样。
5. 任务卡“归档／添加分类”可补生成建议或直接手选，之后还可继续追加，不必重新精读。

修复手动导入后没有触发建议的问题。建议按已有并发上限排队；开启自动建议后，保存笔记会另行排队一次分类请求。已保存人工稿可由用户决定分类，但不会被标为 AI 检查通过；未完成、未保存的稿件仍受保护。

确认时一次校验全部目标、笔记指纹和任务状态，再用原生事务添加。失效目标整体拒绝；保存失败回滚并恢复缓存。模型建议范围只限制模型推荐，不限制用户额外选择当前个人文库分类。

验证：156 项自动检查；8 项多分类归档原生检查及 8 项工作流原生回归通过。使用隔离合成文库和模拟模型；目标失效通过查询故障注入，原生分类写入、回滚和界面多选实际执行。未处理真实论文。
