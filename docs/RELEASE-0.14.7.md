# 0.14.7 — 精读完成后弹出归档确认

日期：2026-11-07；本地构建，未代为安装或发布。

- 笔记保存且建议生成完成后，自动打开独立归档窗口。未完成或未保存的稿件不会提前弹出。
- 设置页只保留全局开关、模型/范围和待确认入口，不再放具体文献卡片。
- 多篇完成时只开一个窗口，依次处理；新建议不会覆盖当前选择。关闭或稍后处理不改变分类，仍可从任务卡/结果窗口重新打开。
- 推荐和移出项默认不勾选；可追加多个分类。移出选项、操作预览与确认按钮固定在底部。
- 确认绑定到当前显示的笔记与原分类，旧弹窗不能作用于被替换的依据。

验证：161 项自动检查、11 项归档弹窗原生检查、8 项工作流回归通过；使用合成文献和模拟模型。截图见 `validation/screenshots-0.14.7/`。隔离测试 profile 禁用内置 Word/LibreOffice 自动安装及欢迎页，避免测试被安装提示干扰；日常配置未由脚本改写。
