# 0.14.25 — 自动按建议归档与保存状态修复

日期：2026-11-09；源码及验证过的 XPI 随本次私有仓库版本提交分发；未自动安装。

## 自动处理归档建议

归档窗口的“按建议处理”上方新增“以后自动按建议处理（包含移出已有分类）”。默认不勾选；勾选并成功处理当前这篇后，后续完成精读且已保存笔记的任务会自动新增推荐分类、移出明确建议调整的分类，未被提及的分类全部保留。来源待处理分类沿用自动归档规则，成功后移出。

设置中也可直接选择“自动按建议处理（新增与移出）”，或切回逐篇确认/原自动模式。旧的待确认记录不因开关变化而补执行。本轮继续复用后台检查已有的分类建议，不额外请求模型；没有有效建议、笔记变化、归属失效或会导致所有分类被移除时，保留现状并提示。

## 保存与中断恢复

- 同次精读已有笔记时，比较当前笔记与本次准备导入的正文。相同才复用；不同则明确提示本次未导入，保留笔记与改稿，不再误报保存成功。此版尚不包含主笔记自动合并/版本管理。
- 生成缓存已清理后，恢复笔记仍重新核对正文指纹；人工修改过的内容不会继续显示原先“已检查”的状态。手动修改保护、一键保存的严格核验保持有效。
- 归档确认中断后，启动时核对已批准方案与真实分类。已执行完成的只恢复确认记录，不重复移动；未完成、笔记变化或无法确认的回到待确认，不自动重放。
- 无法读取的现存工作流不再被当作已清理记录而复用旧笔记。本版未全面解决损坏队列/索引 JSON 的备份恢复。
