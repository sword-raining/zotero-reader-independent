# 0.14.13 — 精简入口与按钮

日期：2026-11-08；本地构建，未自动安装或推送。

- Zotero Reader 右键子菜单从七项缩为三项：精读文献、打开精读结果、设置。多篇选择自动使用批量选择器；多份正文候选和补充材料选择仍由原选择器处理，不因精简菜单自动选正文或读补充材料。
- 再次打开单篇时优先显示现有草稿/任务，不重新生成。正常精读自动解析或复用有效缓存。需要重做时，从结果窗口“更多操作 → 重新精读”发起。
- 队列每篇只展开一个主要入口：查看进度、继续检查/修订、确认归档、查看笔记等，按当前状态选择；停止、其他查看入口等收进“更多”。全局重试和停止收进“队列操作”，暂停/继续及一键清理保留可见。
- 阅读窗口保留当前下一步，保存动作由“导入笔记”改为“保存笔记”，人工稿仍单独标记。底部只保留打开正文 PDF 和更多操作；编辑、归档、刷新、文件夹、重新精读在更多中。
- 强制重新解析移至阅读窗口更多操作，只针对当前正文 PDF，忽略缓存并重新上传 MinerU，不自动重读或改写笔记。常规流程不必操作此项。旧的纯解析和解析预览不再占用常用右键入口。
- 展开的任务菜单在进度刷新时保持；支持 Escape、点击外部和选择操作后收起。不可用操作按状态隐藏，保存/编辑/核验的保护规则继续沿用。

验证：200 项自动检查、19 项隔离原生检查通过（阅读窗口 8、队列/清理/右键菜单 11）。使用合成文库及模拟模型，验证单一主要按钮、菜单刷新/键盘关闭、窄窗口、编辑保护、保存不请求模型、一键清理，以及右键三入口和单/多篇分流。强制解析入口使用回调替身验证当前正文与 force 标记，未请求真实 MinerU。
