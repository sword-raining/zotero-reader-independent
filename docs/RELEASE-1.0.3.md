# 1.0.3 — 修复归档分类为空导致核验请求失败

日期：2026-11-10。

本次可调整的已有分类为空时，旧版本生成了包含空字符串的分类枚举；Gemini 拒绝该请求，返回 `400 INVALID_ARGUMENT`，界面只显示 Antigravity 退出码 3。由于归档建议与核验共用一次请求，该问题会阻断整次核验。

现在空候选集合明确要求返回空数组，不再发送非法枚举；非空集合仍限制为真实分类编号，本地也继续校验允许列表。请求格式错误归类为 OUTPUT_SCHEMA，不再只显示通用退出码。

**已有草稿保留，升级后点击“继续检查”即可，无需删除或重新导入文献。**1.0.2 用户可在 Zotero 检查更新；更早版本仍需手动安装一次新版。

验证：354 项自动检查通过，涵盖推荐/调整候选为空和非空、拒绝虚构分类、错误归类。Antigravity CLI 1.5.3 / Gemini 3.8 Flash High 已用极短合成输入实测接受新 schema，退出码 0；没有提交真实论文或改动个人文库。
