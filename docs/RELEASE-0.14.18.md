# 0.14.18 — 一键保存笔记与停止后继续检查

日期：2026-11-08；本地构建，未自动安装或推送。

- 任务队列有待保存结果时显示“一键保存笔记（N 篇）”。点击后逐篇保存已核验通过、文件未修改的结果；不需要逐篇打开结果，不重新精读或调用模型。
- 正在处理/编辑、已停止、尚未通过检查及已保存的任务不批量导入；发现文件变化、无法确认旧笔记或单篇写入失败时保留稿件并显示原因，其余继续。重复点击不创建另一批任务，同次保存不会重复生成笔记，不覆盖人工修改。
- 保存成功后沿用缓存清理和当前归档方式。自动归档仅采用已有的有效核验建议；无有效建议保留分类，暂停队列时等待恢复后归档。
- 有完整草稿的停止任务提供“继续检查”，从保留稿件继续核验；生成阶段尚未产出完整稿件的任务不显示虚假的结果入口。新取消记录保存来源，旧记录没有来源时明确说明未知。

验证：225 项自动检查通过；7 项隔离原生批量保存与 5 项隔离原生取消续检检查通过。涵盖实际按钮、原生笔记事务、重复保存、修改稿及保存边界变化保护、单篇失败继续、缓存清理后复用、已有建议自动归档、显式续检与无稿回退。真实模型请求 0，未重新启动或导入个人文库任务。生产包 34 个文件与两套原生测试夹具逐文件一致。

截图中的两份停止任务已只读核对：同一时间取消于修订后的复检，草稿完整；旧日志未记取消来源，因此无法追溯具体是哪个停止入口或关闭事件。用户可更新后自行点“继续检查”，不必删除文献重新导入。
