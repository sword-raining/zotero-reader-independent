# 1.0.4 — 已有精读笔记直接跳过

日期：2026-11-10。

已识别到精读笔记的文献默认跳过，不重复调用模型，也不再以“已保存笔记／已有 Zotero 精读笔记”的重复任务出现在队列中。旧的同类记录会自动隐藏，不需要逐条清理。

仅在明确选择“重新精读”，或批量处理时主动取消“跳过已有精读结果”，才按重读流程处理。原笔记不静默覆盖。

本次只调整重复任务的展示和保留统计。PDF、笔记、分类、旧稿及生成文件均不删除；正在检查、有本轮草稿或待确认归档的任务仍显示。内部保留防重复识别记录。

验证：356 项自动检查、13 项 Zotero 10.0.8 隔离原生检查通过。已验证再次批量选择已有精读笔记时跳过、不入队、不调用模型，人工修改旧稿及已有分类保持不变；真实模型请求 0，未操作个人文库。

1.0.2 及以后版本可在 Zotero 检查更新；旧版本可手动安装完整 XPI。按 GPL-3.0-only 发布，保留历史版本。
