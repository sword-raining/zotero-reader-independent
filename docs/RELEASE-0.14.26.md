# 0.14.26 — 独立核心摘要、统一中文筛选与多机协作

日期：2026-11-09；本地源码和安装包已验证，未安装或推送。

## 顶部核心发现

旧逻辑从主要结果中挑第一条不超过 180 字、核验通过的内容作为顶部摘要，不能保证它统领全篇。现在以独立 `coreFinding` 字段随精读生成，具有自己的原文证据和核验编号，与正文同轮检查、同轮修订，不额外加一次模型调用。通过检查后放在文献信息之前，Markdown 与 Zotero 笔记保持一致。

默认模板直接采用用户确认的要求：

> 核心发现（置于文献信息前）：用 1–2 句话直击统领全篇的最终结论。不铺垫背景与问题，不截取开篇局部的过渡性现象；在概括关键变化的基础上，必须落脚到全文最终确立的核心关联、主控因素或关键转折规律。

原有第 7 条“主要结果”及其余十条模板保持。未改动的旧默认模板自动显示新版；自定义模板和已保存笔记不自动覆盖。旧草稿没有独立摘要时不再拿第一条结果填充新的顶部摘要。摘要质量的真实论文/真实模型效果仍需后续观察，本轮仅以合成内容验证独立生成结构、证据覆盖和排版顺序。

## 默认跳过中文

概览增加统一开关，默认开启。自动监听、单篇执行和续检都检查语言；批量仍可对本次取消跳过。语言字段明显为中文或题名明显为中文时识别，题名与英文元数据冲突时尝试本机 PDF 前两页文字；完整解析文本在模型调用前再次判断。英文正文可以纠正中文译名造成的误判。无文字层/识别不充分时仍可能无法准确判断，支持手动取消跳过。

## 多机协作（默认关闭）

可选复用现有 WebDAV 的条件写入领取任务，支持三台及更多机器的重叠队列；处理权失效则停止后续模型/保存操作。成功笔记仍用 Zotero 同步，草稿和解析缓存留在本机。开启前必须通过服务原子能力检测，所有参与端都需安装并开启。仅处理个人文库，尚未实测真实坚果云和三台物理机器。使用方式、暂停/断线/保存保护与限制见 [多机协作说明](COORDINATION.md)。
