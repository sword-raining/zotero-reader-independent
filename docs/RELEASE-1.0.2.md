# 1.0.2 — 接通 Zotero 原生自动更新

日期：2026-11-10。

修复“GitHub 已有新版，但 Zotero 检查更新仍显示没有更新”的配置缺失。此前安装包使用无效的占位更新地址；现在接入固定的公开 HTTPS 更新清单，提供版本、兼容范围、安装包地址和 SHA256，由 Zotero 原生更新器检查与安装。

**1.0.1 及更早版本必须手动安装一次 1.0.2。**旧版无法通过无效地址找到这个修复。之后可使用“工具 → 插件 → 检查更新”；启用 Zotero 的“自动更新插件”后，后续更新由 Zotero 管理。更新需要能访问 GitHub。

安装包继续包含 1.0.1 的一键恢复修复及 GPL-3.0-only 许可证。352 项自动检查、更新清单一致性和重建检查通过；5 项 Zotero 10.0.8 隔离原生检查通过，实测从公开 HTTPS 更新清单发现新版、下载并安装与发布包哈希一致的 XPI，最新版不重复更新。测试旧版副本仅补了有效更新地址；正式旧版仍须手动迁移一次。真实文库和论文任务未操作。

开发发布时，构建 release XPI 后运行 `python tools/update_manifest.py`，再运行 `python tools/check.py --baseline`；同步安装包、updates.json 和校验清单。更新清单不要指向尚未公开的安装包。
