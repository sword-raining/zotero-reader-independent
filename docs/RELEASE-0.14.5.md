# 0.14.5 — 看得懂、可继续的阅读操作

日期：2026-11-07；本地构建，未代为安装或发布远端。

1. 检查中：窗口跟随当前任务更新，不再把打开时的旧状态保留下来。
2. 待修订：直接显示草稿内容、问题原因及对应原文片段；主按钮为“自动修订并复查”。
3. 可导入：主按钮切换为“导入笔记”，这一步不请求模型。
4. 已保存：主按钮切换为“查看笔记”。
5. 人工修改：窗口内编辑、保存后可导入人工修改稿，明确标为未经再次核验；文件被外部修改时拒绝覆盖。

单篇拆组并行已取消，多篇并行保留。自动修订默认开启、最多 2 次，可选 1–5；关闭后仍检查，只不自动改稿。旧设置 0 按关闭兼容。

修复空白模板下拉、截断文件名标题、长作者列表挤占首屏及主要操作不清晰的问题。长题录仅在预览中折叠，笔记内容不删减。

归档必须当前这一轮精读完成并保存对应笔记，且经明确确认；旧建议不能移动待修订、失败或重新处理的文献。确认记录先持久化，分类事务内再次检查状态。

验证：147 项自动检查、8 项阅读界面原生检查、8 项工作流原生检查均通过，全部使用隔离合成文献。截图见 `validation/screenshots-0.14.5/`。实际论文质量/耗时、全部缩放/平台和完整无障碍兼容仍未验证。
