# 0.14.29 — 数字页数与按篇任务标记

日期：2026-11-09；本次公开发布包含完整源码和 XPI，保留 0.14.28 安装包。没有代为安装或改动用户真实文库。

- “PDF 解析 → 解析选项”改为直接输入页数，默认 20，0 表示全部，允许 0–200 的整数。空白、负数、小数和越界输入会提示修正。精读、核验、缓存与已保存笔记识别沿用一致的范围；已有草稿仍保持原范围。
- 可选功能明确为“跨设备任务标记”：只在实际领取任务时记录处理中，其他端跳过已领取任务，保存后记录完成；状态显示在队列，不批量修改未选择的条目，也不因标记改变分类。普通轮换设备无需开启。
- 针对实际诊断中“第一次创建成功、重复创建返回 HTTP 409”的情况修复兼容判断。409 后先读取目标版本；目标确实存在且可读取才按冲突处理。目标不存在或无法确认仍报错，不把所有 409 当作安全冲突。
- 面向普通用户重写 README：安装 XPI、CLI 登录与模型配置、页数、单篇/批量、监听分类、继续检查、保存、归档、换设备和常见错误。明确云解析上传的是所选整个 PDF、页数只限制解析范围。

验证：348 项自动检查通过；针对本次改动完成 20 项隔离原生检查（409 模拟服务上的三客户端各 4 项，设置页 8 项）。41 个生产文件与四套夹具一致，真实模型请求为 0。真实用户文件只读查看了不含凭据的 coordination-diagnostic.json；没有复跑真实云端协作检测，仍按试用反馈逐项修。

0.14.28 的旧稿续检、完整输入传输、前置核心摘要，以及 0.14.27 的超时、索引保护和预检优化均保留。本次没有改变核心精读和核验规则。
