# 0.14.15 — 批量跳过中文论文

日期：2026-11-08；本地构建，未自动安装或推送。

- 批量窗口增加“跳过中文论文（按 Zotero 语言字段）”，每次打开默认开启。取消后仅本批允许中文论文加入；单篇主动精读及自动监听范围不随本选项改变。
- 每篇显示语言标签及字段原值。en/eng/English 等显示英文；zh、zh-CN、zh-TW、zho、chi、Chinese、中文等识别为中文；明确含中文的多语言字段也默认跳过。语言为空或未识别时提示核对，保持可选，不根据中文标题、档案摘要或笔记猜测语言，不写回 Zotero 字段。MinerU 的解析语言设置保持原规则，与批量筛选分开。
- 中文项默认不勾选且不需选择其正文；全选仍遵循语言过滤。预览和提交结果显示跳过数量。入队时重新读取真实字段，不信任旧预览；等待期间语言改为中文时，在解析或调用模型前跳过。取消本选项的批量任务可正常处理中文，已有运行任务不会因再次选择并过滤而中断。
- “跳过已有精读结果”仍默认开启，按已识别结果与资料指纹核对。普通手写笔记不被当作已精读；旧版无充分标记或来源指纹的笔记也不能保证自动跳过。不会覆盖原笔记。首次大量处理建议先抽查小批结果，再扩大范围。
