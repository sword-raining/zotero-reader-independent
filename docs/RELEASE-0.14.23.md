# 0.14.23 — 一键清理重复 PDF，修复已确认的题录归属

日期：2026-11-08；本地构建，未安装或推送。

- 批量附件窗口新增“附件整理”。同篇 SHA256 完全相同的空副本可一键移入 Zotero 回收站；带批注、笔记、标签、引用或任务保护的副本保留，不物理删除原 PDF。
- PDF 首页 DOI 与父题录明确不符时，阻止它被当作本篇正文/补充材料。找到同一文库唯一正确已有题录后，展示目标，可一键修复归属。附件 key、文件路径及批注保留，仅链接该附件的专属批注笔记一起迁移，正文不改。
- 目标已有相同内容 PDF 时清理多余空副本，优先保留带批注/笔记的一份；两份都带保护信息、不同内容或目标不唯一时保留并说明。未下载副本不会被假定相同。
- 整理前后复核来源、引用和归属；迁移与回收使用原生事务，失败回滚。审计留在本机，不写入知识库。界面刷新等待与数据提交分开，刷新未完成时不会误报数据失败或重复执行。

验证：270 项自动检查、22 项隔离原生检查通过，覆盖回收站恢复、附有批注/笔记的迁移、目标已有同内容/不同版本/双批注情况、源和目标变化拦截、真实事务写入后故障回滚、回收站与文库切换。真实模型/云解析请求为 0。35 个生产文件与三套最终夹具一致。

截图中的同名 PDF 已做只读核对：其中一份实际属于另一篇论文，正确题录已存在，目标副本内容相同；未操作这些真实附件。只自动修复 DOI 能唯一确认的已有题录，不扫描全库清理、不猜测新建题录、不合并两份独有批注。

使用：暂停当前任务并等待保存结束，多选要检查的文献 → 精读文献 → 附件整理。选择“一键清理重复 PDF”或“一键修复已确认归属”。安装本包后需重启 Zotero。
