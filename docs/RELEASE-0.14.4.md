# 0.14.4 — 完整精读、并行核验与直接续检

日期：2026-11-07。仅本地构建，未安装个人 Zotero，未推送远端。

- 采用用户提供的唯一统一模板，覆盖实验/观察、Meta 分析、建模及综述。缺失字段简写；发表价值和机制解释使用指定证据标签。
- 保持全文及所有观点核验。正确项返回覆盖编号，只有明确问题输出具体理由与原文依据；不把一般补充建议当成论文审稿要求。缺号、重号或中断不会标为通过。
- 默认同时 2 篇、每篇 2 组，分别可调 1–4；返工上限默认 2，可调 0–5。修改后再次完整核验。每篇状态、输出、取消独立，笔记写入仍用串行事务。
- 队列和结果窗口直接续检/继续修订，保留原稿和原文索引。修复源段落 1800 字符与引句 1200 字符限制不一致造成的误判，不需要删文献重导。
- 默认中英兼容语言包，无需手选；[官方语言文档](https://mineru.net/doc/docs/index_en/#language-value-reference)说明 `ch` 包含中文、英文及繁体。高级设置保留覆盖。
- 保存后加 `AI精读` 标签，并在主笔记开头显示一条已检查的完整主要结果；不修改人工已读标签或原 PDF。
- 归档模型独立配置，默认关闭。先生成现有分类建议，用户可改选并逐篇确认；事务复查笔记指纹与分类归属，只移出原监听分类并加入目标，其他分类保留。

验证：140 项自动检查；Zotero 10.0.8 下 8 项合成端到端检查通过，实测最高 4 个模拟核验同时运行。覆盖自动返工、独立笔记、人工标记/PDF 保护、确认前不移动、笔记编辑阻止旧建议、直接续检不重解析。未运行真实论文或验证新流程的真实模型速度/准确率；真实双机同步仍待验证。
