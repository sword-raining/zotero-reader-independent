# 0.14.10 — 多项推荐与明确的归档完成步骤

日期：2026-11-08；本地构建，未自动安装或推送。

- 后台检查同时推荐 3–5 个有依据的现有分类，按主题、方法、地区等适用维度组织；匹配不足时允许更少，不凑数。不增加正常自动流程的模型调用。
- 检查模型也能针对明确不匹配的已有归属提出移出建议并说明理由；不会因为分类未出现在推荐中就移出，也不代替用户判断个人整理用途。推荐、移出和待处理分类移出均默认不勾选。
- 独立归档窗口先显示已有分类，已加入的推荐没有重复添加勾选框。新增推荐按需选择，额外分类搜索与手动调整默认折叠，底部固定显示新增、移出及保留的结果。
- 不新增分类也可“保留现有分类并完成”；已有其他归属时，可只勾选移出待处理分类。可同时确认新增分类和移出选中的旧归属，未选中的全部保留。移出仅改变此文献的成员关系，不删除分类、PDF 或笔记。
- 事务前检查当前任务和已保存笔记、全部新增/移出分类、当前归属；新增与移出冲突、过期归属、移出后没有任何分类时整体拒绝。保存失败整体回滚；无变化的完成操作不写文献条目。
- 兼容旧版单项建议。旧笔记可主动“更新推荐”，仅使用检查模型请求归档建议，不重读或再次解析 PDF；默认不主动补请求。

操作：已有分类合适时直接完成；要新增或调整时勾选对应项；想退出 `00_新导入文献` 时再勾选移出待处理分类，核对底部清单后确认。

验证：183 项自动检查、15 项隔离原生归档检查、8 项工作流回归通过；使用 Zotero 10.0.8 合成文库和模拟模型。覆盖四项推荐（含已加入项）、旧建议主动刷新为三项、保留现有归属、只移出待处理、选择性调整及新增/移出事务回滚。自动归档仍无额外模型调用；归档测试中一次模型调用来自主动刷新且为模拟请求。

初轮原生测试有旧文案、完成状态及固定分类排序断言未更新，未将失败轮次作为通过证据；最终使用全新隔离 profile 完整复测。未请求真实模型、未归档真实论文，推荐质量仍需后续真实使用评估。截图不是完整无障碍认证；未验证全部缩放、平台或屏幕阅读器。
